
# 🏡 Wanderlust – Airbnb Clone (MERN Stack)

Wanderlust ek **full-stack Airbnb clone** hai jo **MERN Stack** par built hai. Is project me users properties (listings) **create, view, update aur delete** kar sakte hain with **secure authentication & authorization**.

---

## 🚀 Tech Stack

* **Frontend:** React.js, HTML, CSS, Bootstrap
* **Backend:** Node.js, Express.js
* **Database:** MongoDB (Mongoose)
* **Authentication:** JWT, Cookies
* **Authorization:** Role-based & route protection

---

## ✨ Key Features

* 🔐 **JWT Authentication & Authorization**
* 👤 **User Login / Signup**
* 🔓 **Public & Protected Routes**
* 🏠 **Airbnb-style Property Listings**
* ➕ Create, ✏️ Update, ❌ Delete Listings
* 🖼️ Image Upload for Listings
* 🧑‍💼 Only owner can edit/delete their listing
* 📱 Responsive UI (Mobile Friendly)
* ⚡ RESTful API with clean structure

---

## 🔒 Security

* Password hashing using **bcrypt**
* JWT-based protected APIs
* Secure cookies for session handling

## ⚙️ Installation & Setup

```bash
# Clone repository
git clone https://github.com/your-username/wanderlust.git

# Backend
cd backend
npm install
npm start

# Frontend
cd frontend
npm install
npm start
```
